# 💰 Controle de Dívidas - Versão Simplificada

## ✨ Novidades desta versão

- ✅ **Entrada simplificada**: apenas valor da parcela e parcelas restantes
- ✅ **Botão "Pagar"**: marque uma parcela como paga com um clique
- ✅ **Progresso automático**: barras atualizam em tempo real
- ✅ **Próximo vencimento**: calculado automaticamente
- ✅ **Métricas claras**: total, aberto, pago, atrasado

## 📱 Como funciona

1. **Cadastre uma dívida** com:
   - Credor
   - Valor da parcela
   - Parcelas restantes
   - Próximo vencimento
   - Quantas já pagou (opcional)

2. **Acompanhe o progresso**:
   - Barras de progresso
   - Valor total pendente
   - Número de parcelas restantes

3. **Pague uma parcela**:
   - Clique no botão "✅ Pagar"
   - A próxima parcela é automaticamente atualizada

4. **Visualize todas as parcelas**:
   - Clique em "Ver parcelas"
   - Veja histórico completo

## 🎯 Vantagens

- **Mais rápido** de cadastrar
- **Menos cliques** para pagar
- **Visão clara** do que falta
- **Perfeito** para uso diário
